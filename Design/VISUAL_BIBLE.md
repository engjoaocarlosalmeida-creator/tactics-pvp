# TACTICS-PVP
## Visual Bible
### Versão 1.0

# Propósito

Este documento define a identidade visual de Tactics-PvP.

Toda arte produzida para o projeto deve ser comparada contra este documento.

O objetivo não é produzir personagens bonitos isoladamente.

O objetivo é construir um mundo vivo, reconhecível e consistente.

---

# Filosofia Visual

A experiência visual do jogador deve seguir a seguinte ordem:

1. Arena
2. Personagens
3. Efeitos Visuais

A primeira coisa que deve chamar atenção é o ambiente.

A segunda é a leitura clara das classes.

A terceira são os momentos especiais de impacto visual.

---

# Sensação Desejada

O jogador deve sentir:

- curiosidade
- descoberta
- aventura
- mistério
- estratégia

O mundo deve parecer maior do que a batalha atual.

Cada arena deve sugerir que existe uma história além dos limites visíveis do mapa.

# Estilo dos Personagens

## Proporções

Personagens possuem proporções chibi.

Porém não devem parecer infantis.

O objetivo é transmitir:

- personalidade
- peso
- função tática
- presença visual

---

## Nível de Detalhe

Os personagens devem possuir:

- olhos animáveis
- cabelo animável
- roupas com movimento simples

Os personagens não precisam possuir:

- dedos articulados individualmente
- cabelo por fios
- reflexos complexos nos olhos
- detalhes para câmera próxima

---

## Prioridade da Silhueta

A classe é mais importante que a raça.

Ao observar uma unidade distante, o jogador deve identificar imediatamente:

"Cavaleiro"

antes de identificar:

"Humano"

ou

"Goblin"

ou

"Homem-Lagarto".
